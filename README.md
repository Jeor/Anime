# Anime

A collection of 78 anime genre cards, each at **1980 × 1114 pixels**.

[Browse the gallery](https://jeor.github.io/Anime/) · [View the full collection](collection.jpg)

Search by genre, then select a card to open its full-resolution image.

- `cards/`: full-resolution PNG images
- `previews/`: lightweight gallery previews
- `index.html`: responsive, searchable gallery

Anime characters belong to their respective rights holders. This is an unofficial fan collection.

## GitHub Pages

The gallery is published from the root of the `main` branch.
